# 可编辑交互原型

用浏览器直接打开 `index.html`（无需构建）。

## 页面

| 导航 | 对应 PRD | 可做什么 |
|---|---|---|
| 商务 / 开户媒介 / 充值媒介 / 财务 / 老板 | §6 | 看各角色队列与 KPI |
| 开户申请 | §7.2 §8 | 切换本地推 / 非本地推字段；校验 19 位来客 ID |
| 处理开户 | §7.3 | 只读回填；改来客须填原因 |
| 客户四层 | §4 | 看客户→主体→店铺→广告账户，直客 ID 在账户上 |
| 字段模板 | §8.4 | 勾选显示/必填 |
| 工作流 | §9 | 增删节点、改组织规则 |

右上角可切换角色（仅演示身份，不接后端）。演示数据在 `js/app.js`，改文案或队列即可继续设计。
