# 术语表

一句话定义。CRM 列是**可能对应**，未读库表前不当作已建字段。来源路径相对上游知识库 `D:\知识库\巨量引擎`。

| 术语 | 一句话定义 | 在 CRM 中可能对应的字段 | 来源 |
|------|------------|-------------------------|------|
| 巨量引擎 | 字节跳动广告与营销生态总称（Ocean Engine） | 媒体/平台 | `00-总览/首页.md` · `01-巨量引擎/产品地图.md` |
| 巨量营销 | 线索、下载、非闭环电商引流、品牌效果等一体化投放；史称巨量广告/AD，含升级版与智擎版 | 业务类型=常规投放；广告账户 | `01-巨量引擎/巨量营销.md` · `01-巨量引擎/产品地图.md` |
| 巨量千川 | 抖音电商专属营销平台，考核支付 GMV / 支付 ROI | 业务类型=千川；店铺绑定账户 | `02-巨量千川/千川概览.md` |
| 巨量本地推 | 生活服务商家一站式投放：团购成交、到店、本地线索 | 业务类型=抖音本地推 | `01-巨量引擎/巨量本地推.md` |

| 巨量方舟 | 认证代理商的渠道合作台：签约、开户、充值、代投 | 供应商/代理商协作入口，不是广告主投放台 | `01-巨量引擎/工作台与方舟.md` |

| 代理 / 代理商 | 官方认证渠道伙伴，经方舟签约后可代开户、代充值、代投 | 供应商；代理商名称、代理商 ID | `01-巨量引擎/工作台与方舟.md` · `04-销售话术与调研/调研-代理商与服务商公开卖点.md` |
| 渠道（薪火口径） | 用户口述：同行代理/其他公司，名下有多个投流客户 | 账户所属=渠道；客户类型=渠道公司 | 用户口述；上游称「代理商/服务商」见上 |

| account_id | 方舟「千川服务商」路径下管理的千川账户标识 | 假设：千川侧广告账户 ID | `02-巨量千川/开户店铺与资金.md` |
| bp_id | 旧工作台组织账户维度；约 2026-06 中下旬在 46 个 API 停用 | 假设：接近「纵横/工作台组织 ID」，**不是**广告账户 ID | `01-巨量引擎/开放平台/更新日志与公告-2026-09-12.md` |
| 主体资质 | 营业执照等主体证明；须企信网正常、经营范围覆盖推广、与法人一致 | 公司名称、统一社会信用代码、住所 | `01-巨量引擎/开户充值与发票.md` |

| 人店一体 | 抖店官方账号与店铺绑定；解绑则千川与抖音号同步解绑，店与千川不可解绑 | 开户前置校验 | `02-巨量千川/开户店铺与资金.md` |
