## 2. 事业部树（五棵结构相同，以抖音为例）

| 页面 | path | 组件 | 权限串 | 其他媒体对应 |
|---|---|---|---|---|
| 客户管理 | customer | douyin/customer/index | digital:customer:list | otherMedia/customer/index，同权限 |
| 市场主体/公司 | body | douyin/customer/body/index | digital:customersubject:list | 同 |
| 店铺管理 | shop | douyin/shop/index | digital:shop:list | 同 |
| 广告账户 | advertising | douyin/advertising/account/index | digital:advertisingAccount:list | 同 |
| 渠道消耗列表（隐藏） | consumption_dy | douyin/consumption/index | digital:douyinconsume:list | — |
| 广告账户消耗 | consumption | douyin/douyinaccountconsume/index | digital:douyinaccountconsume:list | otherMedia/consumption/index · externalTransfer:consume:list |
| 账户充值 | recharge | douyin/customer/intermediary | — | 同 |
| 转户管理 | transfer | douyin/transfer/account/index | — | 同 |
| 退币管理 | coinreturn | douyin/coinreturn/index | — | 同 |
| 我的 → 现金收款 | my/cashrecharge | **kuaishou**/customer/recharge | — | 同一组件 |
| 我的 → 备款退现 | my/refund | finance/refund/index | digital:money:list | 同 |
| 我的 → 账户充值 / 账户转户 / 账户退币 | | 各树自己的组件 | | |
| 我的 → 待领取收款 | my/receiveRecharge | **kuaishou**/customer/receiveRecharge | digital:receiveRecharge:list | 同一组件 |

结论：五棵树 = 同一组页面的五份拷贝，仅顶层 `types` 不同；「我的」子菜单里现金收款 / 待领取收款连组件都直接复用快手树的。

## 4. 财务管理

在用：现金收款、退现管理、供应商管理、收支账户管理、收支账户流水、导入流水记录（隐藏）。
停用/隐藏：运营和剪辑提成、销售提成、工资管理、现金流水、向供应商支付记录、快手端口、抖音退币确认到账。

## 5. 报表管理（在用 12）

全媒体消耗明细、全媒体消耗环比、抖音运营消耗、客户垫款汇总、垫款分期明细、客户备款汇总、客户充值账户明细、抖音运营日消耗、核对快手账户流水（隐藏）…
停用：日常费用明细汇总、快手运营消耗、各项目收入明细、供应商垫款充值明细表、抖音计提明细、抖音提成表、快手提成计算表、快手运营日消耗、快手/抖音销售消耗预览。
