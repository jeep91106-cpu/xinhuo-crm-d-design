# 开户回复：仅外转（data_type=10）创建广告账户

来源：`DigAccountopenApplyServiceImpl` 约 130–168 行（反编译）。

自有端口走 `else` 只返回「处理成功」，**不插入** `dig_advertising_account`。这是「回复一次、同步再录一次账户 ID」的代码根因。重构要求：两条路径都绑定申请单并落账户。

```java
if (apply.getDataType().equals("10")) {
    // 按供应商名反查 → 用申请单上的 subjectName/shopName/shopNo 文本建账户
    insobj.setShopNo(apply.getShopNo());
    insobj.setSubjectName(apply.getSubjectName());
    insobj.setRemark("开户申请创建账户");
    this.digAdvertisingAccountService.batchInsertAdveraccount(list, "10");
    return AjaxResult.success("处理成功，系统里开户成功账户数量：" + successnum);
}
return AjaxResult.success("处理成功");
```
