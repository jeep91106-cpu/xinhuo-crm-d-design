# M01–M08 与开户字段基线核对

核对对象：完整 PRD V1.0 的 6.1–6.8、6.42，以及《数据关系与客户全景交互补充》。基线提交 f3e78a893dc8857c6fae56bddfb625e3c9499971。

本轮用户最新纠正优先于旧 PRD 中可能产生强制含义的表述：**来客、直客由商务优先填写，均非必填；授权媒介在申请办理页可补全、更正。来客或直客缺失不阻止开户成功。** 非空值仍遵守对应关系、唯一性和变更留痕，不能拿旧编号猜测真实平台身份。

## 数据版本与字段关系

- 当前主体字段保存在公共主体；当前来客名称 / ID 保存在店铺；当前直客保存在申请行或成功账户。
- 原申请保存 subjectSnapshot、shopSnapshot、submittedDirectSnapshot；供应商意向保存 supplierSnapshots。
- 媒介执行保存 requestSnapshot，其中包括 subjectSnapshot、supplierSnapshot、laikeName / laikeId、directName / directId / 来源依据。
- 已有外部成功或待同步的 externalResult 不因主档后续更正变化；后续补 CRM 只引用原成功身份。
- 本地更正均有 localChange / demo 标记。历史真实样本空字段不会被填入演示默认值。
