# M23–M40 运营模块 PRD 覆盖核对

核对基线：`薪火CRM-完整PRD-V1.0.md` 第 6.23–6.40 节及 `src/moduleDefs.json`。工作树为 `operations-fields`，起点提交 `f3e78a893dc8857c6fae56bddfb625e3c9499971`。本页记录本次实际实现及边界，不表示生产功能全部完成。

本次字段均进入模块的录入、保存及详情展示链路。保存成功保留当前模块并打开新记录详情；主要未提交表单向根层报告 `onDirtyChange`。授权检查在动作执行时再次调用，支持 `session.roles` 与 `session.role` 的组合，并拒绝停用、离职、待生效或过期会话。没有连接生产、企微、银行或媒体。
